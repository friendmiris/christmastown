# 크리스마스 마을 — Railway 배포

같은 링크로 들어온 사람들이 실시간으로 서로 보이고, 소원이 같은 나무에 걸리게 하는 서버 포함 패키지입니다.

## 들어 있는 파일

- `index.html` — 마을 화면 (3D, 게임, UI 전부)
- `server.js` — 화면을 내보내고, 접속자들을 실시간으로 이어주고, 소원·썰매 기록을 저장하는 서버
- `package.json` — 실행 설정 (`npm start`)

## 배포 순서

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Railway에서 **New Project → Deploy from GitHub repo** 로 그 저장소를 고릅니다. 빌드·실행은 자동입니다.
3. 서비스의 **Variables** 에 `ADMIN_KEY` 를 추가하고, 관리자 비밀번호로 쓸 값을 넣습니다.
4. 서비스에 **Volume** 을 하나 붙입니다 (마운트 경로 예: `/data`). 붙이지 않으면 다시 배포할 때마다 소원이 지워집니다.
5. **Settings → Networking → Generate Domain** 으로 주소를 만들면 그 주소가 공유할 링크입니다.

## 환경변수

| 이름 | 설명 |
| --- | --- |
| `ADMIN_KEY` | 관리자 비밀번호. 비워두면 소원 삭제 기능이 꺼집니다. |
| `DATA_DIR` | 소원 저장 폴더. Volume을 붙이면 자동으로 그 경로를 씁니다. |
| `PORT` | Railway가 자동으로 넣어줍니다. |

## 관리자로 소원 지우기

마을에서 **소원 모음** 을 열고, 아래쪽 관리자 칸에 `ADMIN_KEY` 값을 넣으면 각 소원 옆에 삭제 버튼이 생깁니다. 지우면 접속 중인 모든 사람 화면에서 바로 사라집니다.

## 내 컴퓨터에서 먼저 해보기

```
npm install
ADMIN_KEY=원하는비밀번호 npm start
```

브라우저 창 두 개로 `http://localhost:3000` 을 열면 서로의 펭귄이 보입니다.
